# Detection of Prescribed-Fire Signals in Observations at Bankhead National Forest
Under what atmospheric and geographic conditions are prescribed fire signals detectable in far-field TBS observations at Bankhead National Forest? 

## Initial Steps
### 1. Build a catalog of candidate prescribed burns.
Dates, names/identifiers, locations, start and end times, area, distance and bearing to ARM site.

### 2. Find TBS Availability
When was TBS operating?
What instruments were actually operating?
What were the actual flight times and altitudes?

### 3. Candidate Selection
Looking for...
- Temporal overlap
- Geographic geometry
- Atmospheric Transport
- Expected plume signal
  - particle count
  - size concentrations
 
### 4. Signal Visibility
If we have candidates that show some signal, can we break that down and explore it further?
1. Concentration signal - Is smoke detectable?
2. Plume signal - How did it arrive?
3. Fire-atmosphere signal - Did the plume modify the boundary layer? (possibly bringing in other obs.)
